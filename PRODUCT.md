# ReelReady

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Implementation choice under the user's instruction to build from scratch: React with the Sites Vinext starter; server-side generation; browser-local drafts. No account or sign-in anywhere. User prioritizes a simple, reviewable first version.

## Users

Solo and team-supported social media creators, especially multilingual Indian creators.

## Product Purpose

Turn one explanation into either a recording plan or an editable publishing kit on one page.

## Operating Context

Installed Wispr Flow dictates into ordinary editable fields. Desktop Command Mode can refine selected text. Typing and examples work without Wispr.

## Capabilities and Constraints

Before recording: hook, outline, shot checklist. After recording: Instagram caption/hashtags, Shorts title/description, X post. Language and script separate. Optional caption examples and brand details. Editable results, copy, character counts, validation, loading, retry and browser-local persistence. No login, schedule, auto-post, dashboard or team workflows. Server secrets only. No invented claims. English, Telugu and Hindi first.

## Brand Commitments

ReelReady. Original voice-wave identity inspired by Wispr Flow. Smooth interface. Speak once. Get your plan and your posts.

## Evidence on Hand

User's detailed accepted specifications in this chat. No verified time-saving benchmark. Sample content must be labelled. Real model connection currently pending.

## Product Principles

Fast first result; no mandatory setup; preserve meaning; review before copying; no repeated entry.
